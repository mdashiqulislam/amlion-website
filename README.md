# AmLion website

Landing page for AmLion Group, built with Next.js, React and TypeScript.

## Two versions saved here

| Name (tag) | What it is |
|---|---|
| `v1-last-version` | The page as it was before the shopper rewrite. |
| `v2-shopper-version` | The updated page, built for Bangladeshi shoppers (current). |

## Run it on your computer

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Where things are

- `src/components/` the page sections (Hero, Story, Trust, Products, and so on)
- `src/data/` the text and numbers shown on the page
- `src/app/globals.css` the styling
- `public/hero/` the hero photo and logo

Product details marked "Sample" are placeholders until AmLion supplies the real ones.
